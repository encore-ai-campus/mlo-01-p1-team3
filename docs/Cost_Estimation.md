# Cost Estimation

본 문서는 [Business Requirements Document](Business_Requirements_Document.md)의 비용 및 빌링 요구사항을 구체화한 계획 예산이다. 기존 AWS 구성안의 최종 범위와 비용 수치를 기준으로 내용을 통합했으며, 실제 계약·청구 금액이 아닌 프로젝트 제안 및 의사결정용 추정치로 사용한다.

## 1. 산정 기준

- 기준 리전: 서울 리전(`ap-northeast-2`)
- 환율 가정: 1달러당 1,400원
- 부가가치세: 별도
- 산정 시점: MVP 구축 및 초기 운영 기준
- 데이터 공급비: 공개·샘플 데이터와 상용 중고차 매물 데이터 비용을 구분
- 데이터베이스 운영비: EC2에 직접 설치한 MySQL·MongoDB의 복제, 백업, 보안 패치 및 장애 대응 비용을 포함

실제 비용은 인스턴스 사양, 저장량, 호출량, 데이터 보관 기간, 장애 대응 수준 및 상용 데이터 계약에 따라 변동될 수 있다.

## 2. 대상 AWS 아키텍처

| 구성 요소 | 수량 | 주요 역할 |
|---|---:|---|
| Bastion EC2 | 1대 | 운영자 SSH 진입 및 Private Subnet 접근 |
| Collector EC2 | 1대 | 자동차 등록·FAQ·중고차 매물 수집 |
| Dashboard EC2 | 1대 | 운영 상태 및 처리 결과 확인 |
| MySQL EC2 | Primary·Standby 2대 | 자동차 등록 데이터 및 운영 이력 저장 |
| MongoDB EC2 | Replica Set 3대 | FAQ 및 중고차 매물 데이터 저장 |
| NAT Gateway | 1식 | Private Subnet의 외부 API·웹사이트 접근 |
| Amazon S3 | 1식 | 원본 파일·로그·백업 저장 |
| CloudWatch·SNS | 1식 | 로그·모니터링·알림 |

자동차 등록 데이터는 MySQL에 저장하고, FAQ와 중고차 매물 데이터는 MongoDB에 저장한다.

## 3. 초기 구축비

| 구분 | 예상 비용 |
|---|---:|
| VPC·Subnet·보안 구성 | 포함 |
| Bastion·Collector·Dashboard EC2 구축 | 포함 |
| MySQL Primary·Standby 구성 | 포함 |
| MongoDB 3노드 Replica Set 구성 | 포함 |
| 자동차 등록·FAQ·중고차 매물 파이프라인 | 포함 |
| Scheduler·Logging·품질검증 | 포함 |
| 대시보드·문서·테스트 | 포함 |
| **초기 구축비 범위** | **약 6,000만~9,000만 원** |
| **기준 예산** | **약 8,100만 원** |

초기 구축비에는 네트워크 구성, 서버 구축, 데이터 수집·전처리·적재 파이프라인, 데이터베이스 이중화·복제, 운영 모니터링, 문서화 및 테스트를 포함한다.

- EBS 저장 공간 및 스냅샷

- MongoDB 3노드 운영 비용

- S3 파일 저장 비용

## 7. 비용 변동 요인과 적용 원칙

- EC2 인스턴스 크기와 가동 시간
- MySQL·MongoDB 데이터 저장량 및 백업 보관 기간
- MongoDB Replica Set 노드 수와 장애 조치 수준
- 자동차 등록·FAQ·중고차 매물 API 호출량
- NAT Gateway 처리 데이터량
- 중고차 매물 수와 갱신 주기
- 이미지 저장 및 CDN 사용 여부
- 상용 데이터 라이선스와 기술지원 범위

EC2에 직접 설치한 MySQL과 MongoDB는 관리형 데이터베이스보다 인프라 비용을 조절할 수 있지만, 복제·백업·보안 패치·장애 조치를 직접 관리해야 한다. 따라서 본 문서의 유지보수비는 단순 서버 사용료가 아니라 해당 운영 책임을 포함한 계획 예산으로 본다.

대규모 트래픽, 고가용성 확대, 사내 시스템 연계, 이미지·CDN 도입 또는 상용 데이터 라이선스가 추가되는 경우에는 별도 견적을 적용한다.

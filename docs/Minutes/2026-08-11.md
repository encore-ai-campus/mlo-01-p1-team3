## 4. 주요 논의 내용


### 안건 1. 프로젝트 주제 확정 및 범위 산정

  **논의 내용**
  - 프로젝트 주제로써 여러 비즈니스 시나리오를 작성하고 이를 통해 하나의 비즈니스 시나리오를 확정한다.
    - 각 솔루션의 특징 파악
    - 데이터 활용 방안 논의
    - 솔루션에 대한 판매 방식 확인

  **결론**
  - 프로젝트 주제는 자동차 제조사 영업·고객지원 데이터 통합 솔루션으로 확정
  - 차량 등록 데이터와 FAQ 데이터를 각각 시장 데이터와 고객지원 데이터로 매칭하여 공급
  (자동차 기준월 1개 + 승인 FAQ page 최대 2개)
  - 기 솔루션 업체의 상업적 특성 및 business model 파악


### 안건 2. 자동차 등록 현황 Source 선정

  **논의 내용**
  - 국토교통부 통계누리 자동차 등록대수 현황 시·도별 OpenAPI 활용 방안 논의
  - 강사 제공 FAQ Source(AutoData Lab)의 접속 방안 및 형식 확인

- **결론**
  - 상기 웹 활용 정형 및 비정형 데이터로 구분하여 Data 적재예정 


### 안건 3. 솔루션 서비스 비용 산정 기준 논의

  **논의 내용**
  - 서비스 초기 구축비, 규모별 구축비, 월 운영비, 차량 데이터 공급 솔루션 비용 및 최종 예산 요약
  - MySQL, MongoDB AWS RDS 비용 산입

- **결론**
  - 솔루션 비용은 전체 파이프라인 유지 비용, 솔루션 판매 비용, 기술지원 및 유지보수 비용을 합산하여 최종 비용 산정


### 안건 4. BRD / PRD 작성 방안 논의

  **논의 내용**
  - BRD : 서비스 배경, 비즈니스 목표, 주요 이해관계자별 요구사항 종합, 프로젝트 범위 산정
  - PRD : 기능, 비기능 요구사항 및 데이터 요구사항 정리

- **결론**
  - BRD에서 문제정의, 목표, 사용자, KPI, 범위를 우선 정리하고 이후 PRD에서 주요 기능과 사용자 시나리오, 데이터 처리 방식, 예외 처리 및 완료 기준을 구체화하여 팀 리뷰를 통해 최종 확정
